1.  **Start Node 1 (e.g., on Port 9999):**
    ```bash

    ```
2.  **Start Node 2 (e.g., on Port 8888):**
    ```bash
    python3 node_main.py 8888
    ```
3.  **Connect Node 2 to Node 1 and send a message:**
